# Robotics Clubs Within ~5 km of São Bernardo do Campo, SP

## Method and important caveats (read before using this list)

I don't have access to a mapping/places API (e.g., Google Places) or the Instagram API in this session, so I could not do a precise, radius-bounded geospatial query or pull live, guaranteed-accurate follower counts. Instead I did iterative web searches (Portuguese and English queries) for "robótica" schools/clubs/teams located in São Bernardo do Campo (SBC), then tried to fetch each organization's own site/Instagram for contact details. Where a page could be fetched directly, the data below is sourced from that page. Where only a search-engine snippet was available (this happens for most Instagram pages, since Instagram blocks/rate-limits automated fetches — I hit repeated HTTP 429s trying to load instagram.com pages directly), I've labeled the data as "via search snippet, unverified" and I explicitly rejected one clearly wrong AI-generated number (a search summary claimed RoboFEI's Instagram has "9M" followers, which is implausible and almost certainly confused with an unrelated equestrian federation account — I did not report it).

A few honesty notes on scope:
- **"Within 5 km of São Bernardo do Campo"** is ambiguous because SBC is itself a city (pop. ~840k) covering a wide area — there's no single point to draw a 5 km radius from other than "the city center." I treated it as **central SBC and the adjoining neighborhoods (Centro, Assunção, Demarchi, Anchieta, Rudge Ramos)**, which is where every organization below is actually located, based on the street addresses found.
- **A pure "robotics club"** (as in, a dedicated hobbyist/competition club with no other business) is a narrow category. In practice, what exists in and around SBC is a mix of: (a) a university competition robotics team (RoboFEI), (b) a public technical school's robotics activities (ETEC Lauro Gomes / SESI), and (c) commercial robotics-education franchises/schools that run robotics as their main or a side offering (SuperGeeks, Código Kid, Colégio B.A., SMARTblocks) plus (d) an industrial-automation training company (Technik) and (e) a general early-childhood school that includes robotics as one of several after-school activities (Recanto Infantil Arte e Magia). I've included all of these and flagged which is which, rather than forcing everything into "club" language that would overstate what they are.
- Several fields (email, WhatsApp, exact follower count) simply were **not published** anywhere I could find for a given organization. Those are marked "Not found" rather than guessed.
- Follower counts are a snapshot from search results in **September 2026** and will drift.

## Bottom line / recommendation

If you need exactly 10 *bona fide, currently-operating robotics clubs* with all four contact fields fully populated, this search didn't cleanly produce that — São Bernardo do Campo has a real but small cluster of robotics-education providers, and the data is genuinely incomplete for several (no public email for most; several Instagram follower counts are search-snippet estimates rather than live pulls, since Instagram blocked direct automated fetches with HTTP 429 during this session). I'd treat items 1–7 and 9 as solid, verifiable leads worth a direct outreach call/WhatsApp to confirm current details, and treat items 8 and 10 as weaker fits (industrial company; unconfirmed local presence, respectively) that you may want to swap out.

For a production-grade version of this list I'd recommend: (a) a Google Places/Maps API text search + radius filter centered on a specific SBC address, and (b) either Instagram's own API/Graph API or a licensed social-data provider — a raw web-search agent like this one cannot reliably pull live follower counts because Instagram actively blocks/rate-limits scraping.
